# Mustafanatur Tap

## How do I install these formulae?

`brew install mustafanatur/tap/<formula>`

Or `brew tap mustafanatur/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "mustafanatur/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
